# Contribuer à Digital Safety

Point d'entrée : https://github.com/HashCode-Reboot/hashcode-contributors.

Le projet doit rester centré sur l'aide aux utilisateurs. Protéger les données des victimes, éviter la culpabilisation et tester les parcours avec de vrais besoins mais sans données personnelles non nécessaires.

Une PR décrit le problème, le parcours, les tests d'accessibilité, les risques et l'impact.
